# 3D-printed enclosure (STL files)

This folder is reserved for the new Makload5000 PRO 3D-printed enclosure models. No STL files have been provided yet; they will be uploaded after they are supplied.

Before printing, verify physical clearance for the Arduino Nano USB connector, LCD, rotary encoder shaft, terminals, cooling fan/heatsink and cable strain relief. Printed plastic must not contact hot MOSFETs or heatsinks. Never assume an untested enclosure is safe at high load power.

Planned: enclosure body, lid, mounting hardware instructions and printing settings. Add photos and a dimensioned drawing once the final enclosure is known.
