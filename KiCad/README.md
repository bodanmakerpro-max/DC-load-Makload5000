# Editable KiCad source

The existing `Petnica DC load.kicad_sch` is retained here so the original circuit can still be opened and edited in KiCad.

**Important:** It is an earlier circuit drawing and has **not** been verified or updated for the Arduino Nano + LCD + encoder + A1 voltage measurement modification. Use [Schematics/NANO-WIRING.md](../Schematics/NANO-WIRING.md) for the updated wire connections. A fully revised schematic and PCB have not been supplied for the new version.
